# 风格参考库

这份文件的 D 维度（数据）补齐动作。
**没有这个库，AI 每次给你的都是它自己的默认审美 —— 那正是「贫瘠」的来源。**

## 怎么用

1. 定方向时，从这里挑 **1~2 个**参考
2. 明确说出**这次学它的什么** —— 配色？留白？字重对比？动效克制？不要笼统说"像它那样"
3. 写完后回来对照：学到了没有

## 怎么攒

- 截图存到 `.claude/skills/ui-style/assets/`，文件名写成 `序号-站名-学到了什么.png`
- 每条记录必须写**「学它的什么」**，写不出来的不要收 —— 那说明你只是觉得它好看，说不出为什么（这正是 I=2 的症状）
- 目标 20~30 条，按类型分组

## 从参考到方向：三步

1. **选 1~2 个**，不要贪多 —— 混三个以上的参考，出来的东西一定是四不像
2. **写一句话**：「这次学 \[站名\] 的 \_\_\_\_，不学它的 \_\_\_\_」
   - 例：学 linear 的字重层级，不学它的深色底（我们这次要做亮色）
3. **定三个变量**：主色、圆角量级、间距节奏。定完再动手

## 这张库同时也是验收标准

界面做出来之后，问一句：

> 把它和选定的参考并排放在一起，看得出是同一个人做的吗？

看不出，就还没到位。这一步比任何主观的"我觉得挺好"都管用。
