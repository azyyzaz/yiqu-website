# 设计变量

**规则：颜色、间距、圆角、字号一律从这里取，不写裸值。**
这里没有你要的值时，先问要不要加，**不要自己造一个近似的**。

当前这批值取自本仓库 `assets/css/style.css` 的 `:root`（参考 deepseek.com 的克制风格）。
**这是起点不是终点** —— 修这份文件要走一次小小的评审，别在写页面的过程中顺手改。

---

## 色板

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | `#ffffff` | 页面底色 |
| `--bg-soft` | `#f5f7fa` | 次级区块背景 |
| `--bg-dark` | `#0a0e17` | 深色区块 |
| `--ink` | `#0d1117` | 正文主色（一级） |
| `--ink-2` | `#4b5563` | 次级文字（二级） |
| `--ink-3` | `#8b94a3` | 说明文字（三级） |
| `--line` | `#e6e9ef` | 分割线 |
| `--line-soft` | `#f0f2f6` | 弱分割线 |
| `--accent` | `#2c55f0` | 主色 |
| `--accent-hover` | `#1f41cc` | 主色悬停 |
| `--accent-soft` | `#eef2ff` | 主色浅底 |
| `--accent-ring` | `rgba(44,85,240,.18)` | 焦点环 |

**三级灰是硬要求**：正文 / 次级 / 说明必须能看出层级。全篇一个中灰是最典型的"没做完"。

**主色的用法**：点缀，不是铺底。一屏里主色出现的面积占比控制在 10% 以内。

## 排版

```
--font-sans: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
             "Hiragino Sans GB", "Microsoft YaHei", "Source Han Sans SC",
             "Noto Sans CJK SC", "Helvetica Neue", Arial, sans-serif;
```

**无网络字体。** 中文环境下加载外部字体会造成明显的闪烁和布局偏移，这个项目不引入。

| 层级 | 字号 | 字重 | 字距 | 行高 |
|---|---|---|---|---|
| 大标题 | 40–56px | 700 | `-0.02em` | 1.15 |
| 区块标题 | 28–32px | 600 | `-0.01em` | 1.3 |
| 小标题 | 18–20px | 600 | 0 | 1.4 |
| 正文 | 16–17px | 400 | 0 | 1.75 |
| 说明 | 13–14px | 400 | 0 | 1.6 |

**字号越大，字距越要收紧。** 大标题用默认字距会显得松散无力。

## 尺寸

| 变量 | 值 | 用途 |
|---|---|---|
| `--container` | `1200px` | 内容最大宽度 |
| `--gutter` | `24px` | 左右留白 |
| `--radius-sm` | `8px` | 标签、小控件 |
| `--radius` | `14px` | 卡片、输入框 |
| `--radius-lg` | `20px` | 大容器 |
| `--radius-pill` | `999px` | 药丸按钮 |

**圆角必须有分级。** 全篇一个值等于没做过取舍。

---

## 节奏

| 变量 | 值 | 用途 |
|---|---|---|
| `--section-y` | `112px` | 区块之间的垂直间距 |
| `--header-h` | `68px` | 顶部导航高度 |

**间距至少分两级**：组内（8/12/16/24px）和组间（`--section-y`）。
组间必须明显大于组内，否则版面会"平"。

---

## 动效

```
--ease: cubic-bezier(.22, .61, .36, 1);
```

时长参考：微交互 150ms，入场 400–600ms。

**每个动效都要有降级路径：**
- `prefers-reduced-motion` 下直接不初始化或改为瞬时
- 触摸屏（`(hover: hover) and (pointer: fine)` 不满足）下不初始化指针相关效果
- 完全禁用 JS 时，内容必须仍然可见（用 `<noscript>` 兜底）
